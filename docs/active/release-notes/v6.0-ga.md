## 📋 v6.0 → v3.0 对比

| 维度 | v3.0 | v6.0 |
|---|---|---|
| 后端语言 | Python (FastAPI) | **TypeScript 全栈** |
| 数据库 | MySQL | **PostgreSQL (Supabase)** |
| 鉴权 | Keycloak | **Supabase Auth + SAML 2.0** |
| 消息 | Kafka + Outbox | **trigger + Webhook + pg_cron** |
| 文件存储 | MinIO | **Supabase Storage** |
| 缓存 | Redis | **Supabase 内置缓存** |
| 业务流程 | Flowable BPMN | **Temporal.io** |
| AI 编排 | 自研 SuperAI + LangChain | **DeepSeek Harness (dsh)** |
| 工作流 | Flowable | **Temporal + SaaS 适配** |
| 向量 | LightRAG | **RAGFlow + pgvector (CLIP)** |
| 前端 | 自研 design system | **Semi Design（直接用）** |
| 代码治理 | 13 硬规则（人治） | **8 CI gate + ADR + evidence（自动化）** |
