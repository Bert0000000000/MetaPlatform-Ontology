# ADR-0066：v6.1 SAML SSO (企业级 SSO)

> **状态**：Proposed
> **日期**：2026-08-20
> **作者**：架构组 + SRE
> **关联 Batch**：MetaPlatform-V6.1-PREP

---

## 1. 背景

大型企业客户要求 SAML 2.0 SSO（对接公司内部 IdP，如 Azure AD / Okta / Auth0）。当前 v6.0 仅支持 OAuth 2.0（钉钉/飞书/企微）+ 邮箱密码。

## 2. 决策

引入 **SAML 2.0 SSO** 适配 Supabase Auth。

## 3. 设计要点

- Supabase Auth SAML provider (官方支持 v2.0+)
- 配置：每个 enterprise tenant 配置 IdP metadata XML
- 用户属性映射：email + role + tenant_id
- 流程：IdP-initiated / SP-initiated 都支持

## 4. 工作量评估

- 4 周 (Supabase 配置 + 测试 + 文档)

## 5. 推迟到 v6.2？

**否** — 大客户门槛需求, v6.1 必做

## 6. 替代方案

- A. 仅 OAuth (拒绝) — 失去大客户
- B. 自建 SAML IdP (复杂度高) — 拒绝

---

*ADR-0066 — SAML SSO 候选 v6.1 must*
