# ADR-0065：v6.1 Multimodal RAG (image / video embedding)

> **状态**：Proposed
> **日期**：2026-08-20
> **作者**：AI 团队
> **关联 Batch**：MetaPlatform-V6.1-PREP

---

## 1. 背景

当前 RAG 只支持文本 (RAGFlow + GraphRAG 文档 chunk)。客户希望上传图片 / 视频也能被检索 ("上传产品图 → 提问相似产品")。

## 2. 决策

引入 **Multimodal RAG**：CLIP / BLIP embedding 支持 image / video。

## 3. 设计要点

- 图片 embedding：CLIP-ViT-Large (1024 维)
- 视频 embedding：BLIP-2 frame-by-frame
- pgvector extension 已支持 (FOUNDATION 安装)
- 检索融合：text score + image score 加权

## 4. 工作量评估

- 10 周 (CLIP 集成 + BLIP 服务 + 多模态融合 + pgvector 索引)

## 5. 推迟到 v6.2？

**是** — 10 周太大 + CLIP 服务自托管 GPU 成本, **v6.1 仅做 PoC, 完整版 v6.2**

## 6. 替代方案

- A. 用 OpenAI CLIP API (vendor lock-in + 成本) — 拒绝
- B. 用 GPT-4V image embedding (多模态 but 慢) — 评估

---

*ADR-0065 — Multimodal RAG v6.1 PoC, v6.2 完整*
