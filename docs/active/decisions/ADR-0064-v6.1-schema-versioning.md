# ADR-0064：v6.1 Ontology Schema 版本管理

> **状态**：Proposed
> **日期**：2026-08-20
> **作者**：AI 团队 + DBA
> **关联 Batch**：MP-V6-V6.1-PREP

---

## 1. 背景

当前 ontology_object_types 单版本 (v1)，apply-ontology-change 直接覆盖。客户希望保留多版本（v1 老合同用旧 schema，v2 新合同用新 schema）。

## 2. 决策

引入 **Ontology Schema 版本管理**：多版本并存 + 应用时指定 version。

## 3. 设计要点

- `ontology_object_types` 增加 `active_version` 字段
- 业务表 schema 演进：增加 `_version` 列
- Temporal workflow version：dsh 用 `version` 区分
- 升级工具：`scripts/etl-schema/migrate_v6_to_v7.ts`

## 4. 工作量评估

- 6 周 (schema 演进 + migration tool + RLS 升级)

## 5. 推迟到 v6.2？

**否** — 已有客户提需求, v6.1 必做

## 6. 替代方案

- A. 强制所有客户升级（破坏性变更） — 拒绝
- B. schema-less (Document store) — 不符合 RLS 强约束

---

*ADR-0064 — Schema Versioning 候选 v6.1 must*
