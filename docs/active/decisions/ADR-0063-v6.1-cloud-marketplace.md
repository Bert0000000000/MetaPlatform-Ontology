# ADR-0063：v6.1 Cloud Marketplace (第三方插件)

> **状态**：Proposed
> **日期**：2026-08-20
> **作者**：架构组
> **关联 Batch**：MP-V6-V6.1-PREP

---

## 1. 背景

生态伙伴需要接入 v6.0 提供自定义 plugin (e.g. 自定义 LLM / 自定义 SaaS 适配器)，但当前无第三方接入通道。

## 2. 决策

引入 **Cloud Marketplace** 第三方插件 marketplace。

## 3. 设计要点

- Plugin manifest (类似 Helm chart values.yaml)
- K8s Operator 模式 (dsp-webhook 路由)
- 沙箱隔离 (dsh sandbox Landlock 已就绪)
- 计费：可选 SaaS 收费 / Freemium

## 4. 工作量评估

- 12 周 (Operator + Plugin SDK + Marketplace UI + 计费 + 安全审计)

## 5. 推迟到 v6.2？

**是** — 12 周太大, v6.1 不可行, **推迟到 v6.2 评估**

## 6. 替代方案

- A. 仅内部扩展点 (extension API, 无 marketplace) — v6.1 简化版
- B. 等 dsh 官方 plugin 系统 — 长期方案

---

*ADR-0063 — Cloud Marketplace 推迟到 v6.2*
