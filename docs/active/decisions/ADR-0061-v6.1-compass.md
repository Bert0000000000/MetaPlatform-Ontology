# ADR-0061：v6.1 Compass (业务智能仪表盘)

> **状态**：Proposed（待 Sprint 4 评审）
> **日期**：2026-08-20
> **作者**：AI 团队 + SRE
> **关联 Batch**：MetaPlatform-V6.1-PREP

---

## 1. 背景

业务用户希望自助生成 dashboard（订单趋势、审批时长、HITL 堆积），但 v6.0 没有原生 dashboard 能力，需要写 SQL 或用 Supabase Studio 手动建。

## 2. 决策

引入 **Compass**（业务智能仪表盘）模块，类 Tableau / Metabase 体验。

## 3. 设计要点

- dsh `dashboard-curator` 数字员工：用户说"显示上月订单趋势" → LLM 生成 SQL → 渲染图表
- 数据源：v6.0 业务表（PostgREST 自动暴露）
- 权限：RLS 自动隔离 + dashboard 可见性 scope
- 缓存：常用 dashboard → Materialized View (PG)

## 4. 工作量评估

- 8 周 (dsh preset + LLM SQL + dashboard 渲染 + Materialized View)
- 风险：LLM 生成 SQL 安全性（必须 dry-run 验证）

## 5. 推迟到 v6.2？

**否** — 业务用户高频需求, v6.1 必做.

## 6. 替代方案

- A. 用 Metabase 自建 (额外组件, 治理债高) — 拒绝
- B. 用 Supabase Studio 内置 dashboard (有限, 不够灵活) — 部分采用

---

*ADR-0061 — Compass 候选 v6.1 must*
