# ADR-0062：v6.1 App Center (数字员工 preset 市场)

> **状态**：Proposed
> **日期**：2026-08-20
> **作者**：AI 团队
> **关联 Batch**：MetaPlatform-V6.1-PREP

---

## 1. 背景

业务团队需要快速复用其他团队的数字员工 preset（如 support-triage / knowledge-curator），但当前 preset 仅限本仓库内, 无法跨租户 / 跨组织共享。

## 2. 决策

引入 **App Center** 数字员工 preset 市场。

## 3. 设计要点

- 公共 preset 仓库 (preset-hub)：中央化托管
- 版本管理：semver, 兼容 dsh session schema
- 多租户隔离：preset per tenant 配置覆盖 (config override)
- dsh runtime 自动下载 + 校验签名

## 4. 工作量评估

- 6 周 (preset-hub + 版本管理 + 签名 + dsh runtime 集成)

## 5. 推迟到 v6.2？

**部分推迟** — MVP (4 个核心 preset) v6.1, 完整市场 v6.2

## 6. 替代方案

- A. 公共 preset GitHub repo (缺少版本控制) — 拒绝
- B. SaaS marketplace (vendor lock-in) — 拒绝
