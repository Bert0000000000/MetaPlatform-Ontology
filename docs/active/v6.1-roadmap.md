| 修复 | `20260820600000_grants_for_ef_writes.sql` |

修掉的 3 个 fail：

1. `edge-functions` #1 create-customer → 500 `permission denied for table customers`
2. `edge-functions` #3 ticket-triage → 500 `permission denied for table hitl_requests`
   - 根因：Edge Function 用 `SUPABASE_SERVICE_ROLE_KEY`，PostgREST `SET ROLE service_role`，
     而 `service_role` 在 `public.*` 上**一条表权限都没有**（`post-restore-fixes.sql` L8 只 GRANT 给 anon/authenticated）
3. `supabase-auth` #2 create-customer tenant 隔离 → `/rest/v1/customers` 返回
   `401 role "admin" does not exist`
   - 根因：`custom_access_token_hook` 把 `profiles.role` 写进 JWT `role` claim，
     而 `role` 同时是 PostgREST 决定 `SET ROLE` 的保留 claim；`owner/admin/member/guest`
     不是真实 PG role
   - 修法：建成真实 PG role 且 `INHERIT authenticated` + `GRANT ... TO authenticator`，
     RLS policy（`TO authenticated`）与 `auth.jwt() ->> 'role'` 判断均不变
